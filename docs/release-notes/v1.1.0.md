完整译文只占第一项，后续选项用于专业英文词组和原句语境解释。

- **Alt+1**：完整译文；取消 1.0.0 的按字符拆分逻辑。
- **Alt+2 起**：专业英文词组、中文释义、本句语境和所在英文句，默认最多 5 个，可配置 0–8 个。
- 新增全文预览、悬停提示和原生 Ctrl+C 复制支持。
- 固定结果排序，关闭使用次数对排序的影响。
- 翻译和词组通过同一次模型调用返回；过滤重复和未出现在原文/译文中的词组。
- 20 项自动化测试通过，包括长文本单项显示、固定排序、结构化输出及词组过滤。

### 升级（保留配置）

退出 Flow，将 `LeoTranslate-1.1.0.zip` 内文件覆盖到原插件文件夹，然后重启。目录名可以保留 1.0.0；不要同时保留两个启用的插件目录。插件 ID 和已有设置字段未改变，无需重新填写原配置。

### 长文本查看

默认结果列表有固定行高；选中第一项按 **F1** 开启全文预览，或在 Flow 设置中开启 Always Preview。悬停提示及复制数据均保留完整译文，长文本不会再占用额外快捷选项。

测试不包含 Windows Flow 图形界面或真实模型接口验证。
