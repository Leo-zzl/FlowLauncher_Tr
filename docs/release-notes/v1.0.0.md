首个公开版本：将输入文本和自定义提示词发送到大模型 API，在 Flow Launcher 下拉结果中显示译文。

- `tr 原文` 自动中英互译；支持 `en`、`zh`、`ar`、`auto` 语言前缀。
- 支持配置 Chat Completions 兼容 API URL、模型、API Key、提示词和超时。
- 默认停止输入 800 毫秒后翻译；可选末尾 `;;` 手动发送。
- 回车复制完整译文；包含错误提示、防抖及旧响应抑制。
- 16 项自动化测试通过，使用本地模拟 API，无需真实密钥。

### 安装

下载 `LeoTranslate-1.0.0.zip`，解压到 Flow 用户数据目录下的 `Plugins/LeoTranslate-1.0.0`，重启 Flow 后在插件设置中配置接口。不要下载 GitHub 自动生成的 Source code ZIP 作为安装包。

### 已知限制

本版本会将长译文拆成多个结果项。建议新用户安装 1.1.0。测试不包含 Windows Flow 图形界面或真实模型接口验证。
